# NBA Database Management System

A Java-based database management application designed to store, manage, and compare NBA player statistics.

This project was developed to apply object-oriented programming, database management, and GUI development concepts in a practical desktop application.

## Features

- Add, view, update, and delete player records
- Store NBA player information in a database
- Compare player statistics
- Interactive desktop user interface
- Database-backed data management

## Technologies

- Java
- JavaFX
- SQLite
- SQL
- Object-Oriented Programming (OOP)

## Purpose

This project was developed as part of my software development coursework and provided hands-on experience with Java application development, relational databases, CRUD operations, and building a graphical user interface.

## What I Learned

Through this project, I gained experience with:

- Designing Java applications using object-oriented programming principles
- Connecting Java applications to a relational database
- Implementing CRUD functionality
- Building desktop interfaces with JavaFX
- Debugging application and database issues
- Structuring a database-driven software project
